# Política de privacidad de Tom Home Assistant

**Última actualización:** 11 de noviembre de 2026

## 1. Responsable

Tom Home Assistant es una skill privada desarrollada para integrar Amazon Alexa con una instalación particular de Home Assistant.

Contacto del responsable: contacto.tomyortega@gmail.com

## 2. Información utilizada

Para funcionar, la skill puede procesar:

- Identificadores y nombres de los dispositivos autorizados en Home Assistant.
- Estados de dispositivos e instrucciones de control, como encender o apagar.
- Tokens de autorización necesarios para vincular una cuenta de Home Assistant.
- Información técnica relacionada con las solicitudes y posibles errores de funcionamiento.

Los comandos de voz son procesados por los servicios de Alexa de Amazon. Esta skill no está diseñada para acceder directamente a grabaciones de audio.

## 3. Finalidad

La información se utiliza exclusivamente para:

- Vincular una cuenta autorizada de Home Assistant con Alexa.
- Descubrir los dispositivos compatibles habilitados.
- Ejecutar las acciones solicitadas mediante Alexa.
- Diagnosticar errores y mantener la integración.

## 4. Servicios utilizados

La integración utiliza Amazon Alexa, AWS Lambda y un servidor privado de Home Assistant.

Estos servicios pueden tratar información técnica necesaria para ejecutar las solicitudes, de acuerdo con sus respectivas condiciones y políticas de privacidad.

## 5. Almacenamiento y conservación

La skill no mantiene una base de datos independiente de perfiles de usuarios.

Home Assistant conserva la información correspondiente a sus usuarios y dispositivos según su propia configuración. Los servicios de Amazon y AWS pueden conservar registros técnicos de acuerdo con sus configuraciones y políticas aplicables.

## 6. Compartición de información

La información necesaria para el funcionamiento se intercambia entre Alexa, AWS Lambda y el servidor Home Assistant autorizado.

No se comercializan datos personales ni se utilizan para campañas publicitarias propias.

## 7. Seguridad

La conexión con Home Assistant utiliza HTTPS y mecanismos de autorización de cuentas.

El acceso a dispositivos está limitado a las entidades habilitadas por el administrador de Home Assistant.

## 8. Revocación y eliminación

El usuario puede desvincular la skill desde la aplicación Alexa.

El administrador de Home Assistant puede revocar las credenciales autorizadas, eliminar usuarios o modificar los dispositivos compartidos.

Para consultas sobre los datos gestionados directamente por esta integración, puede utilizarse el correo de contacto indicado anteriormente.

## 9. Cambios en esta política

Esta política podrá actualizarse si se modifica el funcionamiento de la skill o el tratamiento de la información.
